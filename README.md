# 🫀 Synthetic ECG Signal Generation with Diffusion Models

Welcome to this project on synthetic ECG signal generation using Diffusion Models. This repository contains the complete pipeline for preprocessing the MIT-BIH Arrhythmia dataset, training a Diffusion Model, and generating realistic ECG signals.

![Synthetic ECGs generated by Diffusion Model](./Synthetic%20ECGs%20generated%20by%20Diffusion%20Model.png)

---

## ✨ Features

- **ECG Preprocessing:** A robust pipeline for cleaning and preparing ECG data for deep learning.
- **Diffusion Model:** Implementation of a Diffusion Model for generating high-quality synthetic ECG signals.
- **Modular Code:** The project is organized into Jupyter notebooks for each stage: preprocessing, model training, and sample generation.
- **MIT-BIH Dataset:** Utilizes the well-known MIT-BIH Arrhythmia dataset for training and validation.

---

## 📦 Dataset

This project uses the **MIT-BIH Arrhythmia Dataset**, a widely recognized source of ECG recordings.

- **Source:** [Kaggle - MIT-BIH Arrhythmia (2023)](https://www.kaggle.com/datasets/protobioengineering/mit-bih-arrhythmia-database-modern-2023)
- **Format:** `.csv` files
- **Sampling Rate:** 360 Hz

The dataset is crucial for training the Diffusion Model to learn the underlying patterns of ECG signals. You can download the dataset from the link above and place it in the `data/` directory.

---

## 🧠 Preprocessing Pipeline

The preprocessing pipeline is detailed in the `preprocessing.ipynb` notebook and includes the following steps:

1.  **Bandpass Filtering:** A Butterworth bandpass filter is applied to remove baseline wander and high-frequency noise.
2.  **Normalization:** Each ECG signal is standardized to have a zero mean and unit variance.
3.  **Missing Value Handling:** Ensures data integrity by removing any corrupted or missing entries.
4.  **Column Extraction:** Extracts the raw ECG signal from the CSV files.

---

## 🤖 Diffusion Model

The core of this project is the Diffusion Model, which is trained to generate synthetic ECG signals. The model is implemented in PyTorch and the training process is detailed in the `model_training.ipynb` notebook.

The model learns to reverse a forward diffusion process, which gradually adds noise to the ECG signals. By learning to reverse this process, the model can generate new, realistic ECG signals from random noise.

## 🚀 Usage

To get started with this project, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/USERNAME/REPOSITORY.git
    cd REPOSITORY
    ```
2.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
3.  **Download the dataset:** Download the MIT-BIH Arrhythmia dataset from the link above and place it in the `data/` directory.
4.  **Run the notebooks:** Open and run the Jupyter notebooks in the following order:
    - `preprocessing.ipynb`
    - `windowing_and_dataset.ipynb`
    - `model_training.ipynb`
    - `sample_generation.ipynb`
